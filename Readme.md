# 💪 FitTrack - Aplicación de entrenamientos

## 📌 Idea del proyecto

FitTrack es una aplicación hecha en Java que sirve para organizar entrenamientos de gimnasio de forma sencilla.

La idea es que el usuario pueda elegir un grupo muscular (como pecho, espalda o piernas) y ver ejercicios relacionados con ese músculo. También tiene un sistema de usuarios con registro y login.

Además, existe un usuario administrador que puede ver los usuarios que están registrados en la aplicación.

---

## 🧩 Necesidad del proyecto

Este proyecto nace porque muchas veces cuando alguien empieza en el gimnasio no sabe qué ejercicios hacer ni cómo organizarlos.

Con esta aplicación se intenta solucionar eso de una forma básica, permitiendo:

- Ver ejercicios según el músculo
- Tener una forma sencilla de organizar entrenamientos
- Guardar usuarios en una base de datos
- Tener un sistema básico de inicio de sesión

---

## 👥 A quién va dirigido

Esta aplicación está pensada para:

- Personas que están empezando en el gimnasio
- Usuarios que quieren algo simple para ver ejercicios
- Profesores que quieran ver un proyecto hecho en Java
- Un administrador que puede ver los usuarios registrados

---

## ⚙️ Cosas que tiene la aplicación

- Registro de usuarios
- Inicio de sesión
- Lista de músculos
- Ejercicios según cada músculo
- Usuario administrador para ver datos
- Interfaz sencilla con Java Swing
- Guardado de datos en una base de datos
